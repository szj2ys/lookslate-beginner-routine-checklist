Before you start

Set out what you already have: a base, concealer, powder, brow pencil, mascara, blush and lip color. Add bronzer or a neutral eyeshadow if you want them.

  • Start with less product; add a little more if needed.
  • Check the edges of your base near a window.
  • Keep brushes and sponges clean.
