# Beginner makeup routine checklist

A small, offline checklist published by Lookslate. Use it beside your makeup bag or print your chosen routine. It is an educational guide, not an AI preview or a personalized recommendation.

## Use it

1. Download the project files and open `index.html` in a browser. No installation, server or internet connection is needed to use the downloaded checklist.
2. Leave **Include optional eyeshadow** selected for nine steps, or clear it for eight.
3. Check each step as you go. The count updates on the page.
4. Choose **Print checklist** to open the browser’s print dialog. The selected routine and current checkmarks appear in print. For a blank copy, reset first, then choose whether to include eyeshadow before printing.
5. Choose **Reset checklist** to clear every step and include eyeshadow again.

The checklist needs no account or upload. It uses no tracking or storage and makes no network requests. Choices exist only on the current page. Opening the source link visits an external website and needs an internet connection. With JavaScript disabled, the complete checklist can still be read, checked and printed through the browser menu; the optional-step and reset controls are hidden.

## Accessibility

The page uses native, labeled checkboxes and buttons. Tab moves between controls; Space changes a checkbox; Enter or Space activates a button. Visible focus outlines show the current control, and a polite status message announces the completion count. The optional step is removed from the checklist and keyboard order when excluded. Text reflows for narrow screens, and print styling removes the screen controls.

## Source and scope

The application order and practical tips are adapted from [Lookslate’s beginner makeup routine guide](https://lookslate.com/guides/beginner-makeup-routine).

All HTML, CSS and JavaScript in this resource was written for this checklist. It has no packages, fonts, images, build step or external runtime dependencies.
